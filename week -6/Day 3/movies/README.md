# 🎬 Movies

A Django web application for displaying and viewing movie information.

##  About the Project :

This project was built using Django as part of the Python Web Development Bootcamp.


## 🚀 Features

- Display a list of movies.
- Show movie title, release year, and rating.
- Open a details page for each movie.
- Use dynamic URLs with movie IDs.
- Use Django views and URL routing.
- Use Django templates to display the data.

## 🛠️ Technologies Used

- Python
- Django
- HTML
- Django Templates
